# Equipment rental

This glossary defines the terms used in the equipment rental design and guides.
It records settled meanings. Open product choices remain in the project guides.

## Language

**Equipment item**:
A named catalog entry for rentable equipment, with a quantity and rental rate.

**Guest**:
A visitor who is not signed in.

**Member**:
A user who can create rental requests and manage their own requests.

**Admin**:
A user who manages equipment and members' rental requests.
_Avoid_: Administrator

**Rental request**:
A member's request for one equipment item, a quantity, and a date range.
_Avoid_: Booking, reservation

**Date range**:
The start date and return date selected for a rental request.

**Billable day**:
A calendar date counted within the selected date range, including its start and return dates.

**Rental rate**:
The daily amount used to calculate a rental request's total cost.

**Current rate**:
An equipment item's rental rate at the time its information is viewed.

**Total cost**:
The amount displayed for a rental request's selected date range, using the equipment item's current rental rate and inclusive billable days. Quantity does not change this amount.

**Equipment deletion**:
Removal of an equipment item from the available catalog while retaining its existing rental requests.

**Rental request deletion**:
Permanent removal of a rental request.
