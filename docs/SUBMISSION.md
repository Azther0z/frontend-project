# Submission and presentation

## Submission

The deadline is Wednesday, November 18, 2026, at 23:00 Bangkok time.
Submit the project through MCV, GitHub, and Vercel:

- Push the working frontend to the team GitHub repository.
- Deploy the application on Vercel.
- Submit both URLs in the MCV assignment `PROJECT SUBMISSION`.
- Attach the presentation slides to MCV. Include both URLs in the slides.
- Attach an exported UI design file to MCV. The file must show navigation between screens. A design link in the slides is optional.
- Explain each member's work at the end of the presentation. Prepare GitHub Insights > Contributors as contribution evidence.

The [submission instructions](pdf/Project-Submission-Presentation-Instructions_6aecab16d9430.pdf), pages 1–2 and 4, define these requirements.

## Presentation

Present for seven minutes, followed by three minutes of questions.
Prepare sample equipment and enough requests for the admin demonstration after the member deletes a request.
Demonstrate the deployed application.
Follow this sequence:

1. Explain the assigned problem and UI flow.
2. Register a member and demonstrate invalid input.
3. Log in and browse equipment.
4. Create a rental request and try an invalid request.
5. View, edit, and delete the member's requests.
6. Log out and log in as an admin.
7. View, edit, and delete any member's request.
8. Create equipment and demonstrate optional features.
9. Show contribution evidence, the Vercel deployment, and both URLs.

The [presentation instructions](pdf/Project-Submission-Presentation-Instructions_6aecab16d9430.pdf), pages 3–4, define the sequence and attendance rules.
Equipment updates and deletion remain required system behavior even though this sequence omits them.
