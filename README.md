# Equipment Rental System

Saint and Poom's Course Project 2 lets visitors browse equipment, members request rentals, and admins manage equipment and requests.
The repository contains project documentation and course PDFs. Application folders follow the planned structure below.

## Documentation

Read the guides in this order:

1. [Requirements](docs/REQUIREMENTS.md): system behavior and access rules.
2. [System design](docs/SYSTEM-DESIGN.md): frontend, backend, and database boundaries.
3. [Frontend plan](docs/FRONTEND-PLAN.md): folders, routes, components, and state.
4. [Shared contracts](docs/SHARED-CONTRACTS.md): TypeScript types and component interfaces.
5. [API guide](docs/API.md): backend routes, fields, and limits.
6. [Deployment options](docs/DEPLOYMENT-OPTIONS.md): hosting layouts and deployment tests.
7. [Contribution guide](docs/CONTRIBUTION-HANDOFF.md): ownership, build order, and integration tests.
8. [Design review](docs/POOM-REVIEW.md): criteria for reviewing the system design.
9. [Submission guide](docs/SUBMISSION.md): deadlines, presentation rules, and submission steps.

## Repository structure

The planned application uses these directories:

- `frontend/`: Next.js and TypeScript application.
- `backend/`: Copy of the supplied Express backend.
- `docs/`: Project guides and course PDFs in `docs/pdf/`.

The [supplied backend](https://github.com/SWDevPrac2-69-1/PJ02-EquipmentRent) provides account, equipment, and rental APIs.
Frontend and backend setup follows [FRONTEND-PLAN.md](docs/FRONTEND-PLAN.md).
