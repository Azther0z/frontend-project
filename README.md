# Saint and Poom: Equipment Rental System

Course project: Project 2. This repository contains the project documentation and will contain the Next.js and TypeScript frontend for the supplied equipment-rental backend.

- [Required deliverables](DELIVERABLES.md): required features, submission items, deadlines, grading, and presentation journey.
- [Contribution handoff](CONTRIBUTION-HANDOFF.md): confirmed ownership, backend contract, acceptance checks, integration dependencies, and open decisions.

The [Figma file](https://www.figma.com/design/llQS6sjdaGY3OpBfXf7NVh/Untitled) contains the plain box wireframe screens and prototype connections. Requirements and engineering documentation belong in this repository.

## Contributions

- Saint: public equipment browsing, registration/login/logout, and member rental requests.
- Poom: admin equipment management, admin rental management, and backend/deployment preparation.
- Both: integration checks, review, UI flow review, and presentation/demo preparation.

## Implementation direction

Use English and semantic HTML elements within React. Follow the course's Next.js and TypeScript examples. Add Tailwind utility classes directly in `className` where styling is needed.

The supplied [equipment backend](https://github.com/SWDevPrac2-69-1/PJ02-EquipmentRent) provides authentication, equipment APIs, and rental APIs. Creating a rental request leaves equipment quantity unchanged. Payment and approval are outside the agreed core scope.
